перемешиванием (`genre_plan`: вольт-масса ≥ 13, ниша 5–8, EXQUISITE 1–4,

партий (t5delivery); сцены с динамическим капом (слоты/сцены), причёски без
повторов; В32-гарант (фолбэк eye-метка — глаза всегда в кадре); NEG с
«candle, lamp», без «nude»; R+-сигналы только честные по В43
(`SIGNALS_RPLUS_HONEST`: холд руками / bare-line со стрэпами).

**Чек (инварианты PROTO-2):** жанры/вольт-ядро/бег/EXQUISITE/кин-кап/
канон-локи/окно/дубли/EXP H-XX/RF/сцены/причёски/спред-факт/предикт≡состав/

**Рецепты (specs/rating-recipes.json 1.10.0 → 1.11.0):** RPLUS signals —

   всеми законами; exit-код честный.

   искать причины, а не PASS.

4. Новый закон → тампер-тест в `test_testforge_laws.py` — зуб навсегда.
5. CI и pre-commit держат: деградация невозможна молча.
