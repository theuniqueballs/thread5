## Что это за цех

Конвейер промпт-батчей (тема → контракт → батч → рендер → вердикт →
квитанции). Чат — двигатель, файлы — память. Единственный законодатель —
вердикт автора после рендера. Полная физика: `docs/LAWS.md`; карта
сеансов: `docs/ars/00-OVERVIEW.md`; инженерия: `docs/ENGINEERING.md`.

## Запрещено (молча — никогда)

1. **Один коммит — одна задача.** Смешивать батч с инженерией нельзя.
   Сообщение коммита — осмысленное, не uuid и не «fix».
2. **Новый закон/гейт — только с тестом.** Прежде чем добавлять закон,
   закрой тестом один гейт из списка долгов (`python3 tools/validate.py`
   печатает секции без прямого теста).
3. **Трогать запертые квитанции** `specs/gate-receipts/*.json` и сданные
   батчи задним числом — нельзя (история не переписывается).
4. **Секреты в репо** — PAT/токены/ключи никогда не коммитятся.
5. **Голые счётчики в прозе** — числа (тесты, секции, версии спек) в
   README/ENGINEERING обновляются при каждом изменении руками и
   сверяются с живыми реестрами; рассинхрон = баг.
6. **Волновые реестры между CLOCK-батчами** — новые волны палитр/каналов/
   Y-карт только в LAB по приказу автора (см. MODE ниже).
7. **Вечные баны списков** — кулдаун, не eternal unique (прецедент
   прегарероба: набор в кулдауне 3 партии, затем свободен).

## Перед коммитом (прогонять всё)

```bash
python3 -m unittest discover -s tests/python   # печь
bun test tests/unit                            # прилавок
python3 tools/validate.py                      # валидатор спек (№1–№15)
```

Pre-commit-хук гоняет то же + sha-замок квитанций. Изменённый батч
без свежей квитанции не коммитится:
`python3 tools/gates.py batches/T5-NN.md --json specs/gate-receipts/<дата>-T5-NN-vNN.json --md batches/T5-NN.gate-report.md`

## Режимы цеха (объявлять в брифе ДО сборки)

- **CLOCK** (по умолчанию): жребий по активному пулу Y (траст HIGH+MID
  ≤ 80, `python3 tools/oracle.py draw --for T5-NN --trust`), FURNACE
  LITE, без новых доктрин и major bumps; после вердикта — ≤3 файла
  реестров. Два CLOCK подряд без волн = здоровый цех.
- **LAB**: long tail, новые Y/палитры, A/B — только по приказу автора.
- **SURGERY**: инженерия по багрепорту, не между батчами.
- **SPECIAL**: SO-заказ без полного SOL.

MODE пишется в бриф (`batches/T5-NN/00-brief.md`) и в запись партии в
`specs/delivery-index.json` (поле `mode`).

## Дисциплина слота (CLOCK, кратко)

Claim в первых токенах OPENER; R+ → коридор A|B + один channel-токен
рано; Y-weave 1:1 без меток в POS; палитра ≠ кожа (В36); видимых вещей
из прегарероба ≤ 2; marks 0–1; oc_hook ≤ 1 на батч. Если OPENER не
держит claim — выкидывай mark/gimmick/третью вещь, не claim.
Тема: AXIS/ANTI/PROMISE + фасеты ДО жребия (01-SOL).

## Когда что-то сломалось

`batches/*.gate-report.md`, чини EARTH, не добавляй «ещё гейт».
