Замена HANDOVER-T5-1.md (удалён 2026-11-23, хирургия тройного вердикта:
устаревший «прочти первым» противоречил живому состоянию — 5.1 BETA/10

## Что это за цех

Конвейер промпт-батчей (тема → контракт → батч → рендер → вердикт →
квитанции). Чат — двигатель, файлы — память. Единственный законодатель —
вердикт автора после рендера. Полная физика: `docs/LAWS.md`; карта
сеансов: `docs/ars/00-OVERVIEW.md`; инженерия: `docs/ENGINEERING.md`.

## Запрещено (молча — никогда)

1. **Смешивать батч с ЧУЖОЙ инженерией.** Батч и его СОБСТВЕННЫЕ уроки
   (правки по его вердикту, его гейты, его реестры) — одна задача;
   чужая инженерия — отдельный коммит. Поправка аудита 5.3: закон
   «один коммит — одна задача» в исходном виде исполняется только на
   бумаге (c6d26e1, 263b6b0) — закон, который не исполняется, хуже
   отсутствия закона.
2. **Новый закон/гейт — только с тестом.** Прежде чем добавлять закон,
   закрой тестом один гейт из списка долгов (`python3 tools/validate.py`
   печатает секции без прямого теста).
3. **Трогать запертые квитанции** `specs/gate-receipts/*.json` и сданные
   батчи задним числом — нельзя (история не переписывается).
4. **Секреты в репо** — PAT/токены/ключи никогда не коммитятся (токен
   живёт только в URL remote на время пуша, потом стирается из
   `.git/config`; протокол — `docs/PAT-PROTOCOL.md`).
5. **Голые счётчики в прозе** — числа (тесты, секции, версии спек) в
   README/ENGINEERING обновляются при каждом изменении руками и
   сверяются с живыми реестрами; рассинхрон = баг.
6. **Волновые реестры между CLOCK-батчами** — новые волны палитр/каналов/
   Y-карт только в LAB по приказу автора (см. MODE ниже).
7. **Вечные баны списков** — кулдаун, не eternal unique (прецедент
   прегарероба: набор в кулдауне 3 партии, затем свободен).
8. **Присваивать «муха не еблась» пре-рендерному PASS** (фраза-дисциплина,
   решение автора 2026-11-25, аудит 5.3 §1). До вердикта рендера — только
   «гейты чисты»; «муха не еблась» — исключительно после вердикта автора.
   Факты: T5-31 после «муха не еблась» v1 потребовала хирургию v2 + хотфикс
   v3; T5-32 — эскейп brass после сдачи v1. Исторические коммиты не
   переписываются — правило действует вперёд.

## Начало сеанса (ритуал из AUDIT-5.4 §2.5 — закрыт 2026-11-25)

## Перед коммитом (прогонять всё)

```bash
python3 -m unittest discover -s tests/python   # печь
bun test tests/unit                            # прилавок
python3 tools/validate.py                      # валидатор спек (№1–№15)
```

Pre-commit-хук гоняет то же + sha-замок квитанций. Изменённый батч
без свежей квитанции не коммитится:
`python3 tools/gates.py batches/T5-NN.md --json specs/gate-receipts/<дата>-T5-NN-vNN.json --md batches/T5-NN.gate-report.md`

## Режимы цеха (объявлять в брифе ДО сборки)

- **CLOCK** (по умолчанию): жребий по активному пулу Y (траст HIGH+MID
  ≤ 80, `python3 tools/oracle.py draw --for T5-NN --trust`), FURNACE
  LITE, без новых доктрин и major bumps; после вердикта — ≤3 файла
  реестров. Два CLOCK подряд без волн = здоровый цех.
- **LAB**: long tail, новые Y/палитры, A/B — только по приказу автора.
- **SURGERY**: инженерия по багрепорту, не между батчами.
- **SPECIAL**: SO-заказ без полного SOL.

MODE пишется в бриф (`batches/T5-NN/00-brief.md`) и в запись партии в
`specs/delivery-index.json` (поле `mode`).

## Дисциплина слота (CLOCK, кратко)

Claim в первых токенах OPENER; R+ → коридор A|B + один channel-токен
рано; Y-weave 1:1 без меток в POS; палитра ≠ кожа (В36); видимых вещей
из прегарероба ≤ 2; marks 0–1; oc_hook ≤ 1 на батч. Если OPENER не
держит claim — выкидывай mark/gimmick/третью вещь, не claim.
Тема: AXIS/ANTI/PROMISE + фасеты ДО жребия (01-SOL); THEME-SPEC —
≥3 рендеримых аксиомы + машинострока THEME-ECHO в брифе (В54, с T5-35).

### Сборка R+ (уроки T5-34, В52/В53/В45 — с T5-35)

- **ГЕОМЕТРИЯ-ПЕРВАЯ**: слот с заявкой собирается ОТ позы-геометрии +
  состояния вещи (урок EXP); legacy-карта — поставщик скелета (поза/
  мех-группы/камерный кластер), джус пишется заново; клеймо 1:1 —
  только modern-карты (era-сплит camera 1.23.0, гейт yStamp eraGuard).
- **TWO-CARRIER**: R+ мейн = 2 НЕЗАВИСИМЫХ носителя (геометрия позы +
  материал/состояние вещи); процесс-событие — только второй, никогда
  единственный (15 ложных R+ из 17 в T5-34 были процесс-носителями
  в одиночку).
- **ЭЧЧИ-ПРОТОКОЛ СЛОТА**: заказ «улучши джус, опиши получше»
  исполняется на уровне СЛОТА (PROSE PLUS ядро — второй тег-ран:
  грудь форма+состояние · руки-что-ДЕЛАЮТ · бёдра/попа/кожа, гейт
  voltRun), не реестра — реестры выросли, слоты остались сухими.

### ОС-протокол (В55, вердикт T5-34 — с T5-35)

Тема автора исполняется В ПОЛНУЮ СИЛУ: заявка строится от эротики тела;
камера D2–D4; именные фишки заказа и канон-локи НИКОГДА не в NEG —
даже гард-формой («X removed» глушит токен; гейт negCanonGuard);
переводить тему вниз («вежливые tentacles», «DIRTY — не слово»)
запрещено — вердикт T5-34: все три ОС-темы переосмыслены вниз.

### Квитанции конвейера гипотез (T7.2)

Подтверждённая H (вердикт) обязана родить артефакт для мейнов (карту/
приём/канал) в СЛЕДУЮЩЕЙ партии — полка не копит победы в стол
(H-15 грань-X подтверждена T5-34 → трансфер в мейны по квоте 2–3/батч).
stories.md: каждая карточка несёт смысл-поле «что кадр говорит про её
мир одним предложением» (К-1, обязательное с T5-35).
