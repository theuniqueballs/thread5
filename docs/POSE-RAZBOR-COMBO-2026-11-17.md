# РАЗБОР СОСТАВНЫХ ПОЗ → ДОКТРИНА КОМБО-Y (акт 1, 2026-11-17)

Приказ автора (вердикт T5-24, А): «всю составную позу, которые имеются —
собрать и переделать каждую в доктрину комбо — Y».

## Критерий составности (единый, механический)

Поза составная, если выполнено хотя бы одно:
1. в sd есть второй элемент (объект/среда/партнёр) — словарь 100 лексем
   (on the, mirror, strap, water, him …) — полное слово в razbor-скрипте;
2. sd разбивается на >=4 координированных сегмента;
3. семья построена из карт (y_card_build).

Дисциплина: sd остаётся скелетом в poses.json (семьи не двигались —
family_counts не тронуты), сборка слота — от карты; карта несёт sd
ВЕРБАТИМ (копипаст-юнит).

- всего поз: **568**; составных: **515**; атомарных: **53**

- poses.json 1.16.0 → **1.17.0** (поля combo/card; В27-состояние — честно в trust карты)
