# ARS NOVEAU v2 — СОЛНЕЧНАЯ СИСТЕМА

Карта конвейера. Директива автора (чат, 2026-10-28): ARS NOVEAU — это
промпт для писца, а писец забывчив. Значит не одна стена текста, а
**несколько подпунктов-промптов, выполняемых последовательно**.
Доработка 2026-10-28 (вечер): подвинуты тела, добавлены промежутки —
станция окна, пояс гипотез, стыки, бортовой журнал (санкция автора:
«доработай планеты, подвигай, добавь промежутки»).

## Как читать эту папку

Каждый файл `01–05` — один сеанс работы над батчем. Открыл файл → сделал
работу сеанса → записал выход → закрыл. Файл планеты — это роль, вход,
протокол, выход и гейты этапа. LAWS не дублируется — ссылается.

## Система

```
                     НЕПТУН ┄ архив: verdicts/, LIVING-NOTES
                             (далеко, ходит только FURNACE)
                 УРАН — музей на боку: golden-corpus, EXAMPLE-T4-44
                             (лежит на боку — не достают без нужды)
             САТУРН ◍◍◍ кольца-квоты + burn-реестр
                             (тонкие кольца — входить нельзя)
         ЮПИТЕР — гравитация вкуса (TASTE): масса, гнущая траектории
      ═══════ ПОЯС ГИПОТЕЗ (open-hypotheses.json) ═══════
                             (глыбы; захват глыбы = EXP-слот)

  КОМЕТА (SPECIAL ORDERS) ──── влетает снаружи, короткая орбита

  ┌─ СТАНЦИЯ ОКНА (tools/window.py) — вход в систему:
  │   одна машинная квитанция окна на батч, вписывается в бриф
  ▼
  S O L ──── ядро: идея, HEAT, 24 истории ──── [стык L1]
  ├── ЛУНА — микро-ядро ОС, орбита SOL (сценарии ОС живут здесь)

  VENUS ──── корпус: сцена, свет, живность ──────── [стык L3]
  EARTH ──── сборка: POS/NEG, полировка, гейты ──── [стык L4]
  FURNACE ── ревью, блокнот, PASS/FAIL ──── выход → прилавок
```

## Промежутки (то, что живёт между планетами)

### СТАНЦИЯ ОКНА — вход в систему
Окно ротации (LAWS §7) раньше вычислялось руками трижды за батч — на
SOL, MERCURY и VENUS. Теперь станция считает его один раз:

```
python3 tools/window.py --depth 3 --out batches/T5-NN/window.md
```

Квитанция (позы, палитры, кинетики, носители, каналы последних 3 батчей +
burn-актив) вписывается в бортовой журнал. Все сеансы читают одну
машинную квитанцию, а не перечитывают батчи. Пересчёт — при добавлении
батча в окно.

### ПОЯС ГИПОТЕЗ — между SOL и MERCURY
Полка `specs/open-hypotheses.json` — пояс глыб. SOL **захватывает** глыбу
как EXP-слот (гипотеза + одна переменная A/B + ожидание). После рендера
вердикт возвращает результат на полку: глыба распадается (гипотеза мертва)
или становится луной (закон/данные). Полка не пустеет: EXP ≥5 при непустом
поясе. Захват записан в бриф (глыбы пояса: H-ID…).

### СТЫКИ (L-точки) — контракты между сеансами
У каждого стыка есть контракт — минимальный набор, без которого следующий
сеанс не стартует:

| Стык | Контракт (что обязано быть в артефакте) |
|---|---|
| **L1 SOL→MERCURY** | HEAT объявлена; 24 истории с полями SOL; `cast`-заявки проставлены (где нужны); EXP-глыбы захвачены с полями; бриф обновлён |
| **L2 MERCURY→VENUS** | карточка на каждый слот: кин+RF, тело, волосы/глаза, палитра+раскраска, ДРЕССЕР-решение (одет/покрытие), канал+Stack; все броски записаны |
| **L3 VENUS→EARTH** | план на каждый слот: PL+K, камера, свет НА зоне, свидетель, снятие блокеров + **обязательства-теги** (минимальный список тегов, обязанный попасть в POS) |
| **L4 EARTH→FURNACE** | батч RAW+ полный; gates.py FAIL 0; заметка EARTH приложена |

**Правило стыковки:** сеанс начинается с проверки стыка на входе (1–2
минуты, чек по таблице). Контракт сломан — сеанс НЕ СТАРТУЕТ: фиксируешь
пробел в брифе и чинишь предыдущий сеанс. Не импровизировать поверх дыры
— дыра, переехавшая на следующий сеанс, стоит дороже.

## Солнечный ветер (чат)

Чат — двигатель системы: поручения автора долетают до всех планет.
Правило: **поручение из чата, пришедшее во время конвейера, сразу
фиксируется в бортовом журнале батча** (раздел «Заказ → Поручения чата в
пути») и вписывается в артефакт текущего сеанса. Ветер, не записанный в
бриф, — потерянный ветер (источник: «ты забываешь клёвую хуйню, которую
я тебе предлагаю»).

## Бортовой журнал

`batches/T5-NN/00-brief.md` — один экран состояния батча: заказ, HEAT,
статусы сеансов и стыков, квитанция станции окна, бунты, открытые вопросы.
Шаблон — `batches/_BRIEF-TEMPLATE.md`. Создаёт SOL, обновляют все сеансы.
Вернувшийся к работе (в т.ч. после сброса контекста) читает журнал — не
чат и не память.

## Порядок работы (один батч = до пяти сеансов)

1. Автор даёт тему (+ темы ОС, если заказаны).
2. Сеанс SOL: **стыковка входа** (заказ → бриф по шаблону; прогон
   станции окна → квитанция в бриф; захват EXP-глыб) → `01-sol.md` →
   экспозиция в чате → бриф обновлён, L1 собран.
3. Сеанс MERCURY: стыковка L1 → `02-mercury.md` → бриф, L2.
4. Сеанс VENUS: стыковка L2 → `03-venus.md` (планы + обязательства-теги)
   → бриф, L3.
5. Сеанс EARTH: стыковка L3 → `batches/T5-NN.md` (RAW+ полный) +
   самопрогон `tools/gates.py` → бриф, L4.
6. Сеанс FURNACE: стыковка L4 → ревью артефактов + машинный прогон +
   блокнот → PASS → прилавок → рендер → пост → **вердикт автора**.
7. Квитанции: вербатим — в `verdicts/` + LIVING-NOTES (НЕПТУН, архив);
   урок — планете-владельцу или в LAWS, если это закон; классы ошибок —
   в блокнот FURNACE; результаты EXP — обратно в пояс гипотез.

Петля не изменилась: **чат — двигатель, файлы — память**.

## Дисциплина чтения (анти-забывание)

- За сеанс читаю ТОЛЬКО: файл планеты + его «ЧИТАТЬ ПЕРЕД РАБОТОЙ» +
  артефакты предыдущих сеансов этого батча + бриф.
- Никогда за один сеанс: LIVING-NOTES целиком, TASTE целиком, NICHE
  целиком, любые specs/*.json целиком (только нужные ключи/индексы).
- Следующий сеанс начинается с брифa и стыковки, не с памяти чата.

## КОМЕТА (SPECIAL ORDERS)

SO-NN — комета: влетает снаружи цикла, маршрут укороченный:

```
SOL-light (одна метафора, без движка и 21 истории)
  → MERCURY-light (одна карточка)
    → VENUS → EARTH → FURNACE (все гейты без скидок)
```

Финал — `special/SO-NN.md`. Рейтинг — по заказу, HEAT не объявляется.
Бриф кометы — те же `batches/SO-NN/00-brief.md`.

## Устройства v2 (ждут оплаты вердиктом)

1. **Право на бунт (SOL).** Ради шедевра эччи или шедевра-концепта SOL
   может положить на правило — кроме hard-флоров LAWS §2 (их не гнёт
   никто). Бунт = `break: LAWS §N` + `why:` в истории, ≤2 на батч,
   помечен ⚗, FURNACE не FAIL-ит его, а записывает в блокнот и в бриф —
   платит или убивает вердикт автора.
2. **ULTIMATE DICE (MERCURY).** Палитра, способ раскраски, волосы, глаза,
   кин, гардеробный код — раздача кубиком (`specs/ultimate-dice.json`),
   каждый бросок записан в карточку слота. Переброс легален только на
   коллизию (окно / burn / преткновение / hard-флор) и с записью причины.
3. **Блокнот FURNACE (`specs/furnace-ledger.json`).** Каждый класс ошибки
   проходит состояния: пойман → починен в батче → **искоренён** (правка
   закона / данных / гейта — только через вердикт). Латание текста класс
   не закрывает. Полумер нет.
4. **Стыки и бриф.** Контракты L1–L4 (см. «Промежутки») + бортовой
   журнал: сеанс не стартует без стыковки; ветер чата не минует бриф.
5. **Станция окна (`tools/window.py`).** Окно считается машиной один раз
   за батч, а не руками трижды за сеанс.
