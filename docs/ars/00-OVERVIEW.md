# ARS NOVEAU v2 — СОЛНЕЧНАЯ СИСТЕМА

Карта конвейера. Директива автора (чат, 2026-10-28): ARS NOVEAU — это
промпт для писца, а писец забывчив. Значит не одна стена текста, а
**несколько подпунктов-промптов, выполняемых последовательно**.

## Как читать эту папку

Каждый файл `01–05` — один сеанс работы над батчем. Открыл файл → сделал
работу сеанса → записал выход → закрыл. Файл планеты — это роль, вход,
протокол, выход и гейты этапа. LAWS не дублируется — ссылается.

## Система

```
        ┌────────── ЛУНА (микро-ядро ОС) — орбита SOL
        │
   S O L ── ядро: идея, HEAT, 24 истории
        │
   MERCURY ── спавн: каст, ULTIMATE DICE, ДРЕССЕР
        │
   VENUS ──── корпус: сцена, поза, кинетика, свет, живность
        │
   EARTH ──── сборка: POS/NEG, полировка, агенты-гейты
        │
   FURNACE ── ревью: машинный прогон, блокнот, PASS/FAIL  (экс-MARS)
```

| Этап | Вопрос этапа | Выход (рабочие файлы батча) |
|---|---|---|
| `01-SOL` | О ЧЁМ батч. Что раскрывает каждый слот. Сколько тепла. | `01-sol.md` — идея, движок, ТЕМА-СЛОВА, HEAT, арка, 21 история + 3 истории ЛУНЫ |
| `02-MERCURY` | КТО в кадре. Как выглядит. Во что одет / чем прикрыт. | `02-mercury.md` — карточка слота: кин, тело, волосы/глаза, палитра, раскраска, гардероб/покрытие, канал+Stack, броски костей |
| `03-VENUS` | ЧТО ПРОИСХОДИТ. Корпус кадра. | `03-venus.md` — поза+кинетика, камера, свет, фурнитура, живность, свидетель, снятие блокеров, заявка-в-кадре |
| `04-EARTH` | КАК это звучит тегами. | `batches/T5-NN.md` (черновик RAW+) + самопрогон гейтов |
| `05-FURNACE` | ГДЕ ошибки. | `05-furnace.md` (ревью) + gate-report + блокнот классов |

## Порядок работы (один батч = до пяти сеансов)

1. Автор даёт тему (+ темы ОС, если заказаны).
2. Сеанс SOL → пишет `batches/T5-NN/01-sol.md`, показывает экспозицию в чате.
3. Сеанс MERCURY → `batches/T5-NN/02-mercury.md`.
4. Сеанс VENUS → `batches/T5-NN/03-venus.md`.
5. Сеанс EARTH → собирает `batches/T5-NN.md` (RAW+, полный), самопрогон
   `tools/gates.py`, чинит FAIL.
6. Сеанс FURNACE → ревью артефактов + машинный прогон + блокнот → PASS.
7. Сдано: `batches/T5-NN.md` → прилавок → рендер → пост → **вердикт автора**.
8. Квитанции: вербатим — в `verdicts/` и LIVING-NOTES (архив); урок —
   планете-владельцу (SOL/MERCURY/VENUS/EARTH) или в LAWS, если это закон.
   Классы ошибок — в блокнот FURNACE.

Петля не изменилась: **чат — двигатель, файлы — память**. Изменился
порядок писца внутри кольца «батч».

## Дисциплина чтения (анти-забывание)

- За сеанс читаю ТОЛЬКО: файл планеты + раздел «ЧИТАТЬ ПЕРЕД РАБОТОЙ»
  из него + артефакты предыдущих сеансов этого батча.
- Никогда за один сеанс: LIVING-NOTES целиком, TASTE целиком, NICHE
  целиком, любые specs/*.json целиком (только нужные ключи/индексы).
- Следующий сеанс начинается с чтения артефактов, не с памяти чата.

## КОМЕТА (SPECIAL ORDERS)

SO-NN — комета: влетает снаружи цикла, маршрут укороченный:

```
SOL-light (одна метафора, без движка и 21 истории)
  → MERCURY-light (одна карточка)
    → VENUS → EARTH → FURNACE (все гейты без скидок)
```

Финал — `special/SO-NN.md`. Рейтинг — по заказу, HEAT не объявляется.

## Три устройства v2 (новое, ждёт оплаты вердиктом)

1. **Право на бунт (SOL).** Ради шедевра эччи или шедевра-концепта SOL
   может положить на правило — кроме hard-флоров LAWS §2 (их не гнёт
   никто). Бунт = `break: LAWS §N` + `why:` в истории, ≤2 на батч,
   помечен ⚗, FURNACE не FAIL-ит его, а записывает в блокнот — платит или
   убивает вердикт автора.
2. **ULTIMATE DICE (MERCURY).** Палитра, способ раскраски, волосы, глаза,
   кин, гардеробный код — раздача кубиком (`specs/ultimate-dice.json`),
   каждый бросок записан в карточку слота. Переброс легален только на
   коллизию (окно / burn / преткновение / hard-флор) и с записью причины.
3. **Блокнот FURNACE (`specs/furnace-ledger.json`).** Каждый класс ошибки
   проходит состояния: пойман → починен в батче → **искоренён** (правка
   закона / данных / гейта — только через вердикт). Латание текста класс
   не закрывает. Полумер нет.
