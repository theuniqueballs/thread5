## ЗАКОН СВЕТА — поведение, не прибор (v2, 2026-10-28)

Эмпирика T5-06 (A/B автора): POS-слово прибора сильнее NEG-гарда —
`lamp` стояла в NEG и всё равно заспавнилась; `bulb` в POS дала
лампочку в кадре (в гарде её не было). Замена POS на поведение —
«the light holding the beam line and her chest bright» — прибор ушёл.
NEG-гард — страховка, не лечение.

### Правило
POS не называет осветительные приборы: bulb, lightbulb, lamp, lantern,
candle, torch, chandelier, brazier, headlamp, flashlight, sconce, neon
sign, light fixture. Свет пишем ПОВЕДЕНИЕМ: куда падает, какого цвета,
что делает на зоне заявки. Прибор в кадре — только если он часть образа
(метка [INTENTIONAL] в плане VENUS): тогда имя в POS осознанно, а
приборные слова его NEG-гарда сняты (NEG-линтер: не отрицать
заявленное).

### Формула (1–2 приёма на слот)
направление (overhead shaft · uplight from below · raking side light ·
backlit-rim · off-screen light) → цвет-температура (warm amber, cold
teal) → форма (pool, halo, spill, glow, beam) → на чём (the seam, her
chest line, the wet hem).

### Таблица замены

| POS-прибор (спавнит) | Поведение (не спавнит) |
|---|---|
| the bulb light / lamp light | the light / warm amber glow |
| the loft bulb | the loft light / overhead light |
| lantern | halo of warm light, soft orange spill |
| candle | flickering warm glow, dancing shadows |
| torch, brazier | ember glow, fire-warm spill |
| headlamp, flashlight | focused beam cutting the dark |
| accent on the bulb | accent on the glow / in the light |

разметку: «легально как предмет» / «никогда (IP)».

### 1.1 ONE-MINUTE TEST (обязателен на каждом R+ — постмортем T5-23)

Прикрой окружение рукой — верх промпта (OPENER + CLAIM) заряжен ТЕЛОМ
и заявкой? Тест провален, если верх несёт тему/оружие/среду вместо тела
(«standing into the headwind, spear held vertical» — P06 T5-23: заявка
ушла оружию). Провал = стоп сборки слота: физика Y-карты не вшита — вернись
к плану VENUS, не маж бейдж поверх пустого верха. Результат теста — строкой
в заметке EARTH (слот: PASS/FAIL + что видел).

- **Флаг несовместимости концепта** (conceptFlag, gates 1.12.0): визитка/
  поклон/реверанс/приветствие в R+ без физики заявки — стоп сборки,
  вынос автору с вариантами (понижаем тир / вшиваем физику Y-карты /
  меняем концепт). Молчаливый бейдж запрещён.
- **R-спред тоже несёт раскрытие**: R-бейдж без токена из exposure_r
  (gates.json claimPhysics) — WARN «R-бейдж без раскрытия» (постмортем §5);
  NICHE-слот с полностью одетым телом — честный PG-13, не R.

### 2.9 PRE-GATE ЧЕКЛИСТ (аудит Коула 2026-11-20 §6.1 «сдвиг влево»:
слот сдаётся гейтам УЖЕ зелёным — гейт подтверждает, а не мучает)

[ ] если тир R+: коридор A|B физикой в claim-строке + один ранний
    токен канала доставки (dresser/delivery-stats)

[ ] NEG: все hard-флоры + анти-ваша + candle/lamp
[ ] тема в POS, не в заголовке (название темы не дампится в промпт)

7/8 зелёных — гейт = формальность. Меньше пяти — чини процесс сборки,
а не «протаскивай через гейт». Систематический шум чеклиста — вопрос
FURNACE (см. 05 §5), не повод расслаблять список.

### 3. Полировка (скульптура, слово за словом)

- **Сверка ОБЯЗАТЕЛЬСТВ VENUS** — первое дело полировки: каждый тег из
  списка обязательств либо в POS, либо причина отсутствия записана в
  заметке FURNACE (потерять молча = врать плану).
- Сцена-фурнитура — короткими тегами; проза-обороты в POS запрещены.
- Oмонимы данбуру — только составные (`aurora_(arknights)`).
- Bare-under позитивом: `braless` → нет, `nothing underneath` → да.
- X-доставка: bare-состояние удвоен (теги + face-блок) + блок покрытия
  в NEG (`covered breasts, bra, clothing on chest`) — NEG-блокировка
  покрытия есть инструмент доставки.
- Токен-экономия: убрать двойные смыслы, «the/a/of», многословные единицы.
- Копипаст-бампы разбить: два соседних слота не должны читать один
  фразу-якорь (гейт copypaste).
