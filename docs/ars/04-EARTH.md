## ПРОТОКОЛ

### 1. Сборка POS (шаблон `raw-plus.json`, порядок мастера)

```
anime style, original character, 1girl, solo,
[канон/identity-теги — канон-цвета VERBATIM]   ← ОС
[тело-регистр: 3–5 тегов из карточки MERCURY]
[ЗАЯВОЧНЫЙ БЛОК: именованная тонкая вещь + контакт-геометрия +
 состояние ткани + заявка тира + nothing underneath]
[сцена-фурнитура короткими тегами — из плана VENUS]
[кадрирование тегом]
[палитра sd_fragment + акцент accent1 именованным цветом]
stylized 2D anime face, anime eyes ([цвет, состояние]), small nose, small mouth,
[свет НА зоне заявки]
masterpiece, best quality, anime artstyle.
```

- **SALIENCE**: заявка ≤ токена 60, стоит сразу после канон/тела-блока
  (эталон T4-44). Ранние теги весят больше.
- POS ≤110 слов цель / 150 hard — счётчиком гейта. (Цель 110 — открытый
  вопрос автору, см. OVERVIEW; hard 150 — закон.)
- Способ раскраски MERCURY вписан (палитра-фрагмент), ecchi-ключа НЕТ
  (v1.2.0, присутствие ключа — FAIL).

### 2. Сборка NEG

- Базовый NEG = hard-флоры LAWS §2 (genital lock, anti-loli floor,
  leak guard, candle/lamp guard, milf-запрет...) + wash-блок
  (`washed-out, faded colors, low contrast`) + мёртвые ткани.
- Слоевые/канон-локи слота — из заметок MERCURY (подслой под sheer,
  покрытие, чужие фичи кина).
- **NEG-линтер**: не отрицать то, что заявлено в POS того же слота;
  отрицать НЕПРАВИЛЬНЫЕ варианты (`feathered wings` при wings, blunt
  antlers, human ears). Юнит NEG ≤3 слов — многословный смысловой
  негатив глушит нужное (урок «shadow undressed» T5-05 P23).

### 3. Полировка (скульптура, слово за словом)

- **Сверка ОБЯЗАТЕЛЬСТВ VENUS** — первое дело полировки: каждый тег из
  списка обязательств либо в POS, либо причина отсутствия записана в
  заметке FURNACE (потерять молча = врать плану).
- Сцена-фурнитура — короткими тегами; проза-обороты в POS запрещены.
- Oмонимы данбуру — только составные (`aurora_(arknights)`).
- Bare-under позитивом: `braless` → нет, `nothing underneath` → да.
- X-доставка: bare-состояние удвоен (теги + face-блок) + блок покрытия
  в NEG (`covered breasts, bra, clothing on chest`) — NEG-блокировка
  покрытия есть инструмент доставки.
- Токен-экономия: убрать двойные смыслы, «the/a/of», многословные единицы.
- Копипаст-бампы разбить: два соседних слота не должны читать один
  фразу-якорь (гейт copypaste).
