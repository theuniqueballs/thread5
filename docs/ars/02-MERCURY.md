## ПРОТОКОЛ

### 1. Каст (кто вообще в кадре)

- Расовый каст ~10/21 мейна из `races.json`, только active/gold;
  banned (гномы/гоблины/тролли/орки) — никогда.
- **Кин ≠ гарнитура.** Кин = раса R01–R41, механизм, не костюм: анатомия
  делает физическую работу в кадре. Гарнитура (GAR-код) — одежда, решается
  Дрессером отдельно. Перепутать — FAIL (урок 2026-10-28 «неплохо!»).
- Фичи вида: ≤2 RF на девушку; внутрирасовые коллизии чисты (Sol-лок
  kitsune; LUA/VAE — полн-curl рога + serpentine-хвост = одна фича; DOE;
  ASH-смежность doll+ivory+вуаль). `collision_table`: подписные комбинации
  ОС (Sol/Miyu/Doe/Sue/Vae/Ash/Noa/Nix/Yui) случайным девушкам не достаются.
- Регистры третями: student / young / milf — формой тела, НЕ тегами.
- Тело-регистр: 3–5 тегов формы тела (грудь, бёдра, кожа) — по истории и
  регистру. Канон ОС не трогается никем и никогда.
- **`cast`-заявки SOL — святое**: `kin-want` выполняется кубиком среди
  подходящих рас, `kin-avoid` — вычёркивается из кандидатов. Отклонённая
  заявка (коллизия/окно/burn) — переброс с причиной, строка в бриф
  («отклонённые cast-заявки») — SOL и автор видят, что история потеряла.

### 2. ULTIMATE DICE (раздача, записанная в карточку)

На каждый слот бросаешь и ЗАПИСЫВАЕШЬ бросок в карточку:

| Кость | Источник | Капы на батч |
|---|---|---|
| d-палитра | `palettes.json` | ≥7 различных, ни одна чаще 3×, белая-тонкая-вещь ≤3 |
| d-раскраска | `ultimate-dice.json` paint_methods: пастель / масло / флюоресцентная / контрастная / монохром (+ расширение) | способ воспроизведения вписывается в POS-фрагмент |
| d-волосы / d-глаза | `hair-eye-library.json` | ОС — только канон |
| d-кин | `races.json` | каст-план §1 |
| d-гарнитура | `pools.sections.gar` | ≥10 GAR на батч, ≥4 из GAR21–GAR40 |

- **Переброс легален только на коллизию**: окно ротации, burn-реестр,
  `collision_table`, hard-флор, мёртвая ткань под тир. Причина переброса
  записывается. Всё остальное — сид держит.
- B-половинка A/B-пары (EXP) наследует палитру A.
- Пространство 120+ палитр × 9+ способов раскраски × волосы/глаза × кины —
  повториться почти невозможно, если кости действительно бросаются.

### 3. ДРЕССЕР (одет / не одет / чем прикрыт)

Политика из `dresser.json`: аутфит собирается по политике, а не случайными
предметами.

- Категория сцены (swim/lounge/street/active/formal/specialty/intimates)
  → семейство вещей → GAR-код + состояние ткани (`gar_f`).
- Канал тира → тон/состояние/подслой: `bumps / swim_wet / on_skin /
  pantyline / through / bare`.
- **«Не одет» — тоже решение Дрессера**: чем прикрыт вместо одежды —
  канал доставки заявки (руки, объект, ткань-состояние, кадр). Черновик
  покрытия пишешь ты, доводит VENUS (кадр/свет).
- Состояние ткани по тиру: мёртвые ткани (jeans/leather/velvet/sweatpants/
  suit) заявку не несят (LAWS §3). Через-ткань — только тонкая светлая
  вещь; подслой под sheer лочится в NEG (напиши это в карточку EARTH).
- Слоёвая чёткость: ≤2 слоя одежды на зону тела; зона заявки ≤1 слой.
- Адаптация гардероба под кин: прорезь, подол, пройма — одежда признаёт
  анатомию (хвост, крылья, рога).
- Стек носителей: CR-W/B/E/I/D по каналу (`delivery-stats.json`),
  W-класс ≤45% на батч; каналы-кандидаты (☠) ≤2/батч.
