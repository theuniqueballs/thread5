# ARS NOVEAU — раскрытие темы (простая версия)

Источник: `thread4/docs/ARS-NOVEAU-2026-10-23.md` (ветка thread4.1, эра
«МОЩНОСТЬ»). Переписан для Thread 5: машины нет — раскрытие делаю я, в
чате, ДО тегов. Простое правило: **сначала истории, потом теги.**

---

## 1. Три смерти старого раскрытия

1. **Одна вселенная на 24 кадра** — тема раскладывалась в один набор
   якорей на весь батч → слоты читались вариациями одного кадра
   (T4-32: «стерильно» ×14).
2. **Кубик вместо мысли** — якоря выбирал сид; лексикон перехватывал
   3 измерения из 10. Тема не думалась.
3. **Сюжет слота не существовал** — писец изобретал сцену на лету →
   тема оставалась в THESIS и не доезжала до тегов (T4-45: «P03 нёс
   генерический тезис батча вместо сюжета слота»).

T5-01 повторил всё три (вердикт: «тема кое-как раскрылась»). Лечение ниже.

## 2. Доктрина для T5

До единого тега я пишу ИСТОРИИ:

- **21 историю мейн-пула** — одна история = один слот = ОДИН способ,
  которым тема раскрывается именно в этом кадре;
- **3 истории ОС** — своя история на каждую тему автора;
- **EXP-идеи** — вне темы, только проверки.

Движок/теза/акты/тема-слова рождаются ИЗ историй. Отдельный этап
«сборка» упразднён — его работа поглощена.

## 3. Поля истории (строка на слот, до тегов)

| Поле | Что это |
|---|---|
| `reveal` | ЧТО тема раскрывает именно в этом слоте (одно предложение) |
| `scene` | Что происходит в кадре. **Сущности сцены**: всё, что «действует» (тьма, город, машина), пишется ЭФФЕКТОМ и ПРЕДМЕТОМ — конечность только когда контакт сам является сюжетом слота (причина «ручек отовсюду» T5-04 — актёр с руками в сцене, не теги) |
| `environment` | Место, предметы, физика мира |
| `vibe` | Настроение — рисованными словами |
| `lighting` | Источник, направление, характер |
| `poseIdea` | Идея позы словами (направление; финальная — из библиотеки) |
| `outfit` | Концепт одежды (канал/тон/состояние назначает механика) |
| `character` | Тело/кожа/раса-механика — что канон не закрывает |
| `witness` | (опц.) объект-свидетель — третий глаз кадра |
| `rating` | Целевой тир: `PG-13 / R / R+ / X` (шкала HEAT батча — §4.9) |
| `ratingObject` | Named object заявки с состоянием ткани (`wet thin shirt`, `taped nipples`). R+ и выше — обязателен |
| `ratingCamera` | Как камера участвует в заявке (кадр/угол) |
| `ratingContrast` | Где свет НА зоне заявки (не в декорациях) |
| `ratingBlockers` | Что в кадре может запереть заявку (руки, шаль, подслой) — и как снято |
| `skin` | Кин: код гарнитуры из `pools.sections.gar` + состояние ткани (материал / `gar_f` / канал dresser). Кин не используется — обосновать в этой же строке |
| `expHypothesis` | (только EXP) что проверяем |
| `expVariable` | (только EXP) одна переменная A/B |
| `expExpected` | (только EXP) что ожидаем увидеть |
| `thesis` | Закон кадра одной строкой |

## 4. Законы историй

1. **Рисуемые слова**: каждое существительное — то, что рендерер
   нарисует. Абстракции («dreamlike», «mysterious») запрещены.
2. **Идея-первой** (стандарт P24 T5-01): у слота есть ОДНА большая
   рисованная идея, которую удержишь взглядом. Не «девушка в неоне»,
   а «гигантская голографическая девушка застыла в верхней точке
   вечного прыжка, улица внизу — свидетель».
3. **Тезисы уникальны**: 21 история различаются сценой и законом
   кадра, не синонимами. Гейт: нет двух одинаковых thesis.
4. **Заголовок темы не входит дословно** (закон №26) — тема доезжает
   объектами, светом, физикой мира.
5. **Одна вселенная — 21 вселенная**: каждый слот — свой способ
   раскрытия. Если два слота можно описать одним предложением — один
   переписывается.
6. **OC-закон**: тема ОС обязана дойти до POS-тегов (2–3 отрисовываемых
   тега в тег-ране), не только THESIS. Персонаж несёт ИДЕЮ В СЕБЕ —
   гэг-стек ≥3 крючков, как Сью: двойные косички, повязка на глазу,
   татушка, кожа. Кандидат без идеи — не персонаж, а силуэт. Перед
   изобретением нового лица читаю `specs/oc-canon.json` (штат) +
   `special-roster.json` (гости) и провожу фейс-контроль: «выглядит
   жителем дома — да/нет» (≥2 совпадений с профилем дома). Нет —
   переписывается до сдачи батча.
7. **EXP-закон**: EXP без темы; обязана нести `expHypothesis` +
   `expVariable` (одна переменная A/B) + `expExpected`. Нет гипотезы —
   EXP не создаётся. EXP не копирует мейн-слоты: его задача — проверить
   то, чего в мейне нет.
8. **Закон R+ (до тегов)**: история с `rating: R+` обязана нести ≥2
   жёстких сигнала из LAWS §3 (tier-таблица) и проходить все 9 звеньев
   цепочки салиенса (LAWS §4). Не проходит — переписывается ДО тегов:
   теги не спасут историю, в которой заявки нет.
9. **Закон HEAT**: распределение рейтингов задаётся на батч шкалой HEAT
   и объявляется в шапке. Жанровые диапазоны: NICHE = PG-13…R, VOLT =
   R…R+, EXQUISITE = PG-13…R+, OC — по канон-тейпу (LAWS §5). Дефолт без
   HEAT-заявления — спред LAWS §6 (R+×14 · R×7). «Каждый разок
   по-разному» — легально, но только через явную заявку в шапке.
10. **Закон триггера**: если тема слота попадает в триггер хода из §6
    (колонка «когда применять»), ход обязателен к рассмотрению. Не
    применён — в `thesis` записано, почему.
11. **Закон окна**: перед написанием 21 истории читаю последние 3
    сданных батча и выписываю их позы и палитры (LAWS §7). Ни одна поза
    / палитра окна не повторяется. Повтор неизбежен — слот помечается ⚗
    и объявляется в чате с риском и ожиданием.
12. **Закон бюджета мысли**: по каждому слоту — ВСЕМУ, не только ОС —
    рассмотрено ≥3 ходов из §6 и ≥2 альтернативные идеи (не «девушка в
    неоне», а «гигантская голографическая девушка в верхней точке
    вечного прыжка»). Выбран самый очевидный ход — в `thesis` записано,
    почему альтернативы отвергнуты.

## 5. Печь (числовой гейт перед сдачей)

Последняя инстанция перед сдачей. Каждый пункт — счёт, а не ритуал.
FAIL хотя бы одного = батч не сдаётся, истории переписываются ДО тегов.

1. **R+ аудит** — каждая история с `rating: R+` и выше: ≥2 жёстких
   сигнала (LAWS §3) + все 9 звеньев (LAWS §4). Любое звено отсутствует
   — FAIL, история переписывается.
2. **Кин-аудит** — каждый слот с `skin`: код существует в
   `pools.sections.gar`, состояние ткани соответствует тиру (мёртвые
   ткани заявку не несут — LAWS §3). На батч ≥10 различных GAR и ≥4 из
   GAR21–GAR40 (`wardrobe_usage`). Кин забыт или не из библиотеки —
   FAIL.
3. **Триггер-аудит** — каждый слот, чья тема попала в триггер хода §6:
   ход рассмотрен; не применён — причина записана в `thesis`. Пусто —
   FAIL.
4. **Окно-аудит** — позы и палитры не повторяют последние 3 сданных
   батча (LAWS §7). Повтор без ⚗ и объявления в чате — FAIL.
5. **EXP-аудит** — каждый EXP несёт гипотезу, переменную, ожидание.
   «Просто промптик» — FAIL.
6. **OC-аудит** — каждый OC/кандидат: запись фейс-контроля (ссылка на
   профиль дома из `oc-canon.json`, ≥2 совпадений) + гэг-стек ≥3
   крючков в самом персонаже. Без идеи — FAIL.
7. **Бюджет-аудит** — по каждому слоту рассмотрено ≥3 ходов §6 и ≥2
   альтернативы; очевидный ход без записанного обоснования в `thesis` —
   FAIL.
8. **Спред-аудит** — факт рейтингов == заявленному спреду в шапке батча
   (дефолт R+×14 · R×7 — LAWS §6; HEAT-сдвиг только явной заявкой).

После счёта — письменный ответ себе (не вместо, а после):

- **Гейты** — что поймал, что ПРОПУСТИЛ (сверить находки с текстом).
- **Тема** — раскрыта ли каждая из 21 историй В КАДРЕ (адресно, по слоту).
- **Итог** — что получилось, что нет, почему. Без прикрас.

## 6. Валидированные ходы (вера, оплаченная вердиктами)

Ходы попадают сюда только после вердикта. Не плодить до оплаты.

1. **Вертикальный закон одного события** (SO-01 v2 «САД НА ОДИН ВЫДОХ»,
   оплачен общим вердиктом): кадр читается снизу вверх как жизнь одного
   события — рождение у нижней кромки, раскрытие у лица, распад у верхней;
   героиня неподвижна, движется только событие. Использовать, когда заказ
   = одна метафора, а не сцена.
2. **Анти-открытка** (урок SO-01 v1): жанровая сценка + безупречная
   техника = «очень обыкновенный». Верхний грейд обязан держать
   невозможное, читаемое первым силуэтом.
3. **Построчный канон-чек чужих референсов** (урок SO-01 v1): перед сдачей
   канон сверяется с референсом построчно — мелочи (волоски в чёлке,
   родинка, шрам) весят больше композиции, промах по ним ранит адресата.
4. **Остановленный мир** (T5-04 P08, оплачен вердиктом «любимчики»):
   заморозка города как сцена — толпа застыла в шаге, стакан висит над
   асфальтом, дым стоит стеной; движется только героиня. Мир-стоп =
   способ выделить тело без камеры-вектора. **Когда применять:** тема
   про изоляцию / остановку времени / наблюдение.
5. **Ловля на пролёте** (T5-04 P11): предмет, брошенный между крышами,
   пойман в воздухе — физика доставки как сюжет, доверие как содержимое.
   **Когда применять:** тема про доставку / доверие / риск.
6. **Луна-груз** (T5-04 P24, EXQUISITE, вердикт: «охуенно, это просто
   бомба»): ноль-гей челнок к Луне, куда продаётся всё; всё лёгкое в
   кадре летит к окну. Финал батча = самая тихая физика и самый
   невозможный груз. **Когда применять:** тема про лёгкость /
   невозможный груз; финал батча.
7. **Предмет > состояние** (T5-04 P13 — единственный выживший R+):
   эротика рендерится ВЕЩЬЮ с формой и положением (X-тейп на каждом
   соске, открытый бомбер на голой груди), а не нарратив-фразой о
   «честной линии». **Когда применять:** R+ слоты — заявка = вещь, не
   фраза; фраза уходит в THESIS или становится тегом.

## 7. Развитие на T5-03 (roadmap автора)

- **ВOLT**: у каждого VOLT-слота своя физика слота — закон ткани/света,
  который двигает тело (мокрый подол отстаёт, тяга вверх ведёт пряди);
  камера-участник читается из физики, не из прилагательных.
- **NICHE**: свидетель = сама среда. Тьма с руками — третий глаз кадра:
  невозможное делает не реквизит, а пространство, и свидетель держит кадр
  даже без зрителя. *(Уточнено вердиктом T5-04 → бафф B2: свидетель =
  эффект и предмет, конечность — только когда контакт и есть сюжет.)*
- **Палитры-игра**: тип раскраски как драйвер истории слота (монохром
  одной краски / призма-сплит на чёрном / тушь с единственным цветом /
  лак с единственным цветом / инфракрасный тепловизор) — сначала тип
  раскраски, потом сюжет, который без него невозможен.

## 8. Кляуза на ARS NOVEAU — вердикт автора на баффы (2026-10-27, ночь)

План баффов B1–B4 разобран кляузой: не писать новую доктрину — встроить
недостающее в существующие разделы. Вердикты на баффы и где живёт лечение:

- **B1 «экки-ключ» — «круто, но ситуативно».** Рейтинги пересматриваются
  под батч по шкале HEAT: NICHE = PG-13…R, VOLT = R…R+, EXQUISITE =
  PG-13…R+, «каждый разок по-разному». → §3 поле `rating`, §4.9 закон
  HEAT, §5.8 спред-аудит. `ecchi anime style` остаётся ключом R+-тегов
  (LAWS §6 шаблон), но тир начинается историей, не тегом.
- **B2 «невидимая прислуга» — «полная хуйня из под коня».** Симптом
  вместо причины: ручки — ошибка уровня ИСТОРИИ (актёр с конечностями в
  сцене), а не тегов; квоты на `tar-black` лечат следствие. → §3 поле
  `scene` (сущности сцены = эффект и предмет; конечность только когда
  контакт и есть сюжет) + §5.1/гейты. Движки будущих батчей пишутся без
  сущностей-актёров по умолчанию.
- **B3 «флагман» — «я хочу чтобы ВСЕ слоты были проработаны».** Лизать
  две категории = нахуя тогда батч. → план-уровень слота един для всех:
  §4.12 бюджет мысли и §5.7 бюджет-аудит действуют на каждый слот без
  исключений; ОС — на общих основаниях, лавры ОС — из вердикта, не из
  квоты.
- **B4 «лицо дома» — «не понял что это за хуйня».** Кандидаты провалились
  не по хаус-луку, а по отсутствию ИДЕИ В ПЕРСОНАЖЕ («простые»). Эталон
  плотности — Сью: двойные косички, повязка на глазу, татушка, кожа. →
  §4.6 OC-закон: гэг-стек ≥3 крючков в самом персонаже + фейс-контроль
  по `oc-canon.json` (профиль дома — носитель стандарта плотности, не
  фильтр внешности).

Исполнение кляузы: §3 (+9 полей), §4 (+5 законов, обновлены 6–7), §5
(печь = 8 числовых аудитов), §6 («когда применять» на ходах), синхрон
LAWS §3/§4. Первый прогон — T5-05.
