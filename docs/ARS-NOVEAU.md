# ARS NOVEAU — раскрытие темы (простая версия)

Источник: `thread4/docs/ARS-NOVEAU-2026-10-23.md` (ветка thread4.1, эра
«МОЩНОСТЬ»). Переписан для Thread 5: машины нет — раскрытие делаю я, в
чате, ДО тегов. Простое правило: **сначала истории, потом теги.**

---

## 1. Три смерти старого раскрытия

1. **Одна вселенная на 24 кадра** — тема раскладывалась в один набор
   якорей на весь батч → слоты читались вариациями одного кадра
   (T4-32: «стерильно» ×14).
2. **Кубик вместо мысли** — якоря выбирал сид; лексикон перехватывал
   3 измерения из 10. Тема не думалась.
3. **Сюжет слота не существовал** — писец изобретал сцену на лету →
   тема оставалась в THESIS и не доезжала до тегов (T4-45: «P03 нёс
   генерический тезис батча вместо сюжета слота»).

T5-01 повторил всё три (вердикт: «тема кое-как раскрылась»). Лечение ниже.

## 2. Доктрина для T5

До единого тега я пишу ИСТОРИИ:

- **21 историю мейн-пула** — одна история = один слот = ОДИН способ,
  которым тема раскрывается именно в этом кадре;
- **3 истории ОС** — своя история на каждую тему автора;
- **EXP-идеи** — вне темы, только проверки.

Движок/теза/акты/тема-слова рождаются ИЗ историй. Отдельный этап
«сборка» упразднён — его работа поглощена.

## 3. Поля истории (строка на слот, до тегов)

| Поле | Что это |
|---|---|
| `reveal` | ЧТО тема раскрывает именно в этом слоте (одно предложение) |
| `scene` | Что происходит в кадре |
| `environment` | Место, предметы, физика мира |
| `vibe` | Настроение — рисованными словами |
| `lighting` | Источник, направление, характер |
| `poseIdea` | Идея позы словами (направление; финальная — из библиотеки) |
| `outfit` | Концепт одежды (канал/тон/состояние назначает механика) |
| `character` | Тело/кожа/раса-механика — что канон не закрывает |
| `witness` | (опц.) объект-свидетель — третий глаз кадра |
| `thesis` | Закон кадра одной строкой |

## 4. Законы историй

1. **Рисуемые слова**: каждое существительное — то, что рендерер
   нарисует. Абстракции («dreamlike», «mysterious») запрещены.
2. **Идея-первой** (стандарт P24 T5-01): у слота есть ОДНА большая
   рисованная идея, которую удержишь взглядом. Не «девушка в неоне»,
   а «гигантская голографическая девушка застыла в верхней точке
   вечного прыжка, улица внизу — свидетель».
3. **Тезисы уникальны**: 21 история различаются сценой и законом
   кадра, не синонимами. Гейт: нет двух одинаковых thesis.
4. **Заголовок темы не входит дословно** (закон №26) — тема доезжает
   объектами, светом, физикой мира.
5. **Одна вселенная — 21 вселенная**: каждый слот — свой способ
   раскрытия. Если два слота можно описать одним предложением — один
   переписывается.
6. **OC-закон**: тема ОС обязана дойти до POS-тегов (2–3 отрисовываемых
   тега в тег-ране), не только THESIS.
7. **EXP-закон**: EXP без темы; гипотеза + A/B одной переменной; EXP
   существует чтобы ПРОВЕРЯТЬ (концепт ниши, новая поза, одежда, кин,
   OC-канон) — и больше ни для чего.

## 5. Печь (самопроверка перед сдачей)

Последняя инстанция перед сдачей — письменный ответ себе, по слотам:

1. **Гейты** — что поймал, что ПРОПУСТИЛ (сверить находки с текстом).
2. **Тема** — раскрыта ли каждая из 21 историй В КАДРЕ (адресно, по слоту).
3. **Писец** — фейс-лок, канон-вербатим, форма тег-рана, NEG-флоры,
   бюджет тира, контр-NEG каналов.
4. **Итог** — что получилось, что нет, почему. Без прикрас.

FAIL по п.2 = батч не сдаётся, истории переписываются.

## 6. Валидированные ходы (вера, оплаченная вердиктами)

Ходы попадают сюда только после вердикта. Не плодить до оплаты.

1. **Вертикальный закон одного события** (SO-01 v2 «САД НА ОДИН ВЫДОХ»,
   оплачен общим вердиктом): кадр читается снизу вверх как жизнь одного
   события — рождение у нижней кромки, раскрытие у лица, распад у верхней;
   героиня неподвижна, движется только событие. Использовать, когда заказ
   = одна метафора, а не сцена.
2. **Анти-открытка** (урок SO-01 v1): жанровая сценка + безупречная
   техника = «очень обыкновенный». Верхний грейд обязан держать
   невозможное, читаемое первым силуэтом.
3. **Построчный канон-чек чужих референсов** (урок SO-01 v1): перед сдачей
   канон сверяется с референсом построчно — мелочи (волоски в чёлке,
   родинка, шрам) весят больше композиции, промах по ним ранит адресата.
4. **Остановленный мир** (T5-04 P08, оплачен вердиктом «любимчики»):
   заморозка города как сцена — толпа застыла в шаге, стакан висит над
   асфальтом, дым стоит стеной; движется только героиня. Мир-стоп =
   способ выделить тело без камеры-вектора.
5. **Ловля на пролёте** (T5-04 P11): предмет, брошенный между крышами,
   пойман в воздухе — физика доставки как сюжет, доверие как содержимое.
6. **Луна-груз** (T5-04 P24, EXQUISITE, вердикт: «охуенно, это просто
   бомба»): ноль-гей челнок к Луне, куда продаётся всё; всё лёгкое в
   кадре летит к окну. Финал батча = самая тихая физика и самый
   невозможный груз.
7. **Предмет > состояние** (T5-04 P13 — единственный выживший R+):
   эротика рендерится ВЕЩЬЮ с формой и положением (X-тейп на каждом
   соске, открытый бомбер на голой груди), а не нарратив-фразой о
   «честной линии». Базис баффа B2.

## 7. Развитие на T5-03 (roadmap автора)

- **ВOLT**: у каждого VOLT-слота своя физика слота — закон ткани/света,
  который двигает тело (мокрый подол отстаёт, тяга вверх ведёт пряди);
  камера-участник читается из физики, не из прилагательных.
- **NICHE**: свидетель = сама среда. Тьма с руками — третий глаз кадра:
  невозможное делает не реквизит, а пространство, и свидетель держит кадр
  даже без зрителя. *(Уточнено вердиктом T5-04 → бафф B2: свидетель =
  эффект и предмет, конечность — только когда контакт и есть сюжет.)*
- **Палитры-игра**: тип раскраски как драйвер истории слота (монохром
  одной краски / призма-сплит на чёрном / тушь с единственным цветом /
  лак с единственным цветом / инфракрасный тепловизор) — сначала тип
  раскраски, потом сюжет, который без него невозможен.

## 8. СЕРИЯ БАФФОВ ARS NOVEAU — заказ автора (вердикт T5-04, 2026-10-27)

Автор: «нужно как-то развить именно творческий потенциал… ARS NOVEAU
нужна серия баффов». Диагнозы вердикта → четыре баффа. Каждый бафф =
правило + файл-носитель + гейт приёмки. Выполняется до сборки T5-05.

### B1 — «ЭККИ-КЛЮЧ» (реестр R+)

**Правило:** каждый R+-слот открывается тегом `ecchi anime style`
(вторым тегом POS, по паттерну T4-44: 24×) и несёт ≥2 жёстких сигнала
из rating-recipes.json (RPLUS-тир: covered nipples / taped nipples /
breast clinging / wet clothes / visible pantyline / nothing underneath
/ handbra…). Тело — формой: `slender womanly body, soft settled breasts`
или `slim athletic body, small breasts, softly mounded` (не голое
`slim body, small chest`). Сенсорика — тегом: `sweat glistening`,
мокрая кожа. **Дисциплина:** эротическое состояние = короткий
danbooru-тег; нарратив-фразы («the pantyline's top edge honest in the
stopped arc») в POS запрещены — фраза либо становится тегом, либо уходит
в THESIS.

**Носители:** rating-recipes.json (гейт signal_min для R+), _TEMPLATE.md
(R+ чеклист), LAWS.md §2-строка про R+.

**Гейт приёмки:** программный — каждый R+ POS содержит `ecchi anime
style` + ≥2 RPLUS-сигнала + shaped-body тег; 0 нарратив-фраз о
состоянии тела.

### B2 — «НЕВИДИМАЯ ПРИСЛУГА» (анти-ручки)

**Правило:** тьма-экипаж действует ЭФФЕКТОМ и ПРЕДМЕТОМ, не конечностью:
стена дождя висит (без ладоней), стакан уже изъят, одеяло поправлено,
крио-ритм задан. Рука тьмы в POS — максимум ОДНА на слот и только когда
контакт сам является сюжетом слота (эталон P13: ладони собирают волосы).
`tar-black` — не более 8× на батч (T5-04: 23×). НЛГ-щит: в NEG каждого
слота с рукой тьмы — `extra arms, extra hands, disembodied limbs`.

**Носители:** engines.json / engine-forge.json (движковая запись),
_LAWS/чеклист ПЕЧИ.

**Гейт приёмки:** греп батча — `tar-black` ≤8; каждый слот ≤1 руке;
NEG-щит на месте; THESIS описывает следствие, не конечность.

### B3 — «ФЛАГМАН» (OC-крафт)

**Правило:** ОС-слоты — самые проработанные слоты батча, не «как все»:
канон целиком (все anti-shield поля), проп-подпись канона в кадре, тема
ОС = главная идея кадра (не декорация), R+ сигнал по тиру, своя
мини-драматургия в THESIS (завязка-поворот-тишина). Сборка батча
начинается с ОС-слотов, а не заканчивается ими.

**Носители:** _TEMPLATE.md (OC-чеклист), oc-canon.json (usage_policy —
уточнение «флагманский слот»), ПЕЧЬ.

**Гейт приёмки:** ОС-слот длиннее среднего мейна по THESIS+POS; канон
verbatim; проп-подпись присутствует; вердикт-вопрос «над этим
постарались?» — снят.

### B4 — «ЛИЦО ДОМА» (хаус-фит кандидатов и новых OC)

**Правило:** EXP-кандидаты и любые новые лица обязаны нести хаус-лук:
перед изобретением персонажа читаются oc-canon.json (12 в штате) +
special-roster.json (гости) — выводится профиль дома (палитры волос/глаз,
регистры, предмет-подпись, вайб), кандидат проходит фейс-контроль:
«выглядит жителем дома — да/нет». Не проходит — переписывается до
сдачи батча.

**Носители:** specs/oc-body-archive.json или новый specs/house-look.json
(профиль дома одним JSON: валидированные комбинации), EXP-закон в
ARS-NOVEAU §4.7.

**Гейт приёмки:** каждый кандидат имеет запись хаус-фита (ссылка на
профиль, ≥2 совпадения); вердикт-вопрос «какие ОС могут приняться в
штат» — снят.

### Порядок работ

1. B1 (экки-ключ) — самый дорогой по вердикту, чинит тир целиком.
2. B2 (прислуга) — чинит «ручки отовсюду».
3. B3 (флагман) — ОС-слоты.
4. B4 (лицо дома) — кандидаты, новый specs/house-look.json.
5. Обкатка — T5-05: все четыре баффа в бою, гейты программно.
