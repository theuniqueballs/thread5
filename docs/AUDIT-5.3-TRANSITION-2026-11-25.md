## 1. Диагноз

Система machine-сильна как никогда: fail-closed инбокс, sha-замок
квитанций, полный pre-commit за ~3 с, реестр гейтов «объявлено ≡ исполняется»,
единственный индекс сдачи, побитовый паритет трёх органов на золотых
векторах, JSON-вердикты как канон вкуса. Два батча уровня Т5-30 подряд
(T5-30, T5-31) — эмпирическое доказательство, что архитектура ЦИКЛА 4
работает. Это надо зафиксировать жёстко: **основу 5.3 трогать нельзя**.

Но система начала врать себе в трёх местах. **Первое — язык**: фраза
«муха не еблась» прикреплена к моменту ДО рендера (гейты 0F/0W), тогда как
оба последних батча потребовали пост-сдача-фиксов для классов, которые гейты
принципиально не видят — джанк-реквизит, brass-цветокор, калибровка R+
(263b6b0, 89159d4: латунное слово поймано «уже ПОСЛЕ сдачи v1»). Качество
держится не машинами, а вниманием писца + глазом автора; машины держат
механику. **Второе — жизненный цикл**: реестры только растут — T5-28 висит
в `ready` четвёртый день и печатается статусом неотличимо от свежего;
волны палитр входят как «trial до вердикта» без правила промоции; траст-слой
видит 4 партии из 31. **Третье — доктрина рейтинга** живёт в пяти местах,
а её свежейшая часть (эталон P28, В44) не поддержана ни одной машиной:
ratingTruth работает на словарях ДО-В44 и, значит, цифра «состав-R+ 26/26»
в коммите T5-32 несёт заверение старой калибровки — той самой, которая
пропустила «много где» у T5-31 v1.

## 2. Аудит по четырём осям

### 2.1. Работоспособность и хрупкость

**Подтверждённая сила (перечислить, чтобы не «улучшать» работающее):**
единая арифметика сдачи (t5delivery — все читатели переключены), fail-closed
культура (инбокс/валидатор/pre-commit), стражи на стражей (187+124+тамперы),
вербатим-культура законов, паритет оракула, секрет-гигиена — проверено
сканами сегодня, утечки нет.

- **[High] «Муха не еблась» врёт о моменте истины.** LAWS §9 честно говорит
  «гейт ≠ вердикт», но операционный словарь (коммит-сообщения, квитанции)
  уже присваивает фразу пре-рендерному PASS. Факты: T5-31 — после «муха не
  еблась» v1 потребовались хирургия v2 (рейтинг-калибровка, В44) и горячий
  фикс v3 (джанк/brass/NEG-кнопка); T5-32 — brass-слово в POS P04 поймано

  сдачи на батч» нигде не живёт, хотя это единственная честная мера
  пре-рендерной слепоты конвейера: на последних двух партиях она равна 2 и 1.
- **[High] Хирургия без рендера = обещания без данных.** T5-31 после v2/v3
  больше не рендерится (решение автора: «генерить его не буду»). Значит:

  метки рендера v2» — НЕ ПРИДЁТ никогда. ratingTruth продолжает работать на

- **[High] Класс «призрак» жив, эскалации нет.** T5-28 `ready` с 2026-11-21

### 2.2. Доктрины, законы и правила

- **[High] «Один коммит — одна задача» мёртв на практике.** AGENTS.md §1:
  «Смешивать батч с инженерией нельзя». Факты: c6d26e1 (батч T5-31 + аудит +
  вердикт + реестры), 263b6b0 (хирургия батча + парсер прилавка + реестры +

  ростер + техника). Причина системна: уроки батча И ЕСТЬ батч. Закон, который
  исполняется только на бумаге, хуже отсутствия закона — он приучает агента
  к выборочному слушанию. Лечится поправкой: «батч и его собственные уроки —
  одна задача; чужая инженерия — отдельный коммит».
- **[High] Рейтинг-доктрина в пяти источниках истины.** LAWS §3/§4/§8 →

  ДОКТРИНУ между файлами (тесты пинируют только словари). Это тот же
  «снежный ком», который двойной аудит убил для счётчиков.
- **[High] LAWS «читается целиком перед каждым батчем» — ритуал.** 785
  строк + 27 секций + 44 урока + 6 ARS-доков + raw-plus + чек-листы.

- **[Medium] Латентность уроков не формализована.** В24 (джанк/brass) вошёл

- **[Medium] Легаси-текст живых законов.** LAWS §5: «EXP… по умолчанию 2» —

## 3. Пути слияния в один организм (механизмы, не пожелания)

Принцип: не добавлять слои — сливать существующие органы и ужесточать
контракты. Каждое предложение опирается на живые механизмы.

1. **Калибровочный мост В43/В44 (вердикт → машина).** Органы: инбокс
   (слот-матчинг зрением уже есть), verdicts/*.json, словари ratingTruth,
   taste.py. Механизм: в схему t5-verdict/1 добавляется поле
   `rating_truth_delta[]` (слот → предсказанный машиной тир vs факт автора) —
   автор заполняет его после рендера одним взглядом (по спорным слотам);
   oracle/taste считает дельту словарей и предлагает правку (LAB, по слову
   автора «калибровка принята»); после правки перезапинивается калибровочный
   тест TestRatingTruthCalibration. ЭтоProposal из AUDIT-5.4 §2.3, не
   исполненный тогда — пере-предъявлен с механикой. Эффект: рейтинг —
   домен №1 по жалобам (T5-29: 17 ложных R+; T5-31: «много где») — получает
   2-батчевый цикл честности вместо «отложено навсегда».
2. **LAWS → LAWS-MACHINE + LAWS-CRAFT (сплит одного файла, не новый слой).**
   MACHINE: всё, что исполняют гейты — писцу не нужно это помнить, гейт
   поймает (≈70% текста). CRAFT: остаток, который машина видеть не может —
   одна страница, читать перед каждым батчем вместо 785 строк: эталон-P28
   тест («дороже или дешевле P28 по прикрытию?»), джанк-семантика (носимое
   vs спавн), brass-семейство слов, разнообразие фраз честности (урок
   сборки №3 T5-31: единая формула сама стала копипастом), глубина
   исследования темы (§16), one-minute test, гигиена POS («,,», задвоения).
   Эффект: внимание писца концентрируется ровно там, где случаются
   эскейпы 1–2/батч.
3. **t5delivery → страж призраков и приборная полоса.** Одна функция в
   единственном модуле сдачи: `ready` старше 3 дней → строка ALARM;
   `delivered` без verdicts/*.json старше 2 дней → ALARM (класс T5-30);
   количество версий квитанции партии > 1 → печатать как «hotfix N» в
   status. Убивает класс призраков (два события за последние 4 дня) и
   делает пре-рендерную слепоту видимой метрикой без единого нового органа.
4. **Round-trip копировалки на живом корпусе.** parse.ts + прогоны на всех
   batches/*.md и special/*.md: parse → печать POS/NEG → нормализованный

   dividerTitle умирает целиком, а не по экземпляру.
5. **Реестровая диета.** Влить pools.json в closet.json (legacy признан в
   MERCURY), rating-recipes в rating-techniques, oc-body-archive в приложение
   oc-canon; правило для 5.3: «новый реестр в домене с дублем — только
   вместе с ретирацией дубля» (один вошёл — один вышел). Энтропия источников
   истины становится управляемой величиной, как счётчики после двойного
   аудита.
6. **Жизненный цикл волн палитр.** (AUDIT-5.4 §2.2, открыт до сих пор.)
   Слово автора в вердикте («волна принята») → trial→canon; непринятая волна
   старше 2 партий не перекатывается; проверка №16 в валидаторе.

**Рычаги максимального воздействия (малое изменение → большой эффект):**

| # | Рычаг | Цена | Эффект |
|---|---|---|---|

**Высокорискованный, потенциально трансформационный ход — СБОРЩИК-ЧЕРНОВИКА.**
Инфраструктура уже стоит: жребий оракула раздаёт констелляцию, pregarment
катает комбо, ystamp.ts печатает вплетение 1:1 из id карты, волны палитр
рождаются скриптами, testforge уже собирает 21-слотовые болванки с полными
манифестами. Ход: печь собирает 70% слота (OPENER-кластер + COMBO-WEAVE +
фурнитура SCENE + PALETTE + FACE — всё из реестров, копипаст-юниты без
пересказа), писец крафтит только 30% (CLAIM-строка, THESIS, история,
рейтинговый состав) поверх черновика. Режим LAB, одна партия, фальсифицируемая

атрофия ремесла при успехе. Награда: стоимость батча падает с полного сеанса
до часов, всё внимание писца уходит в слепые зоны гейтов. Гейт решения —
вердикт партии.
