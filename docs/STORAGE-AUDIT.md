## 4. Решения (внесены сегодня, v2 конвейера)

1. **ARS NOVEAU делится на планеты** — `docs/ars/00…05`: последовательные
   сеансы-промпты. SOL → MERCURY → VENUS → EARTH → FURNACE, ЛУНА на орбите
   SOL. Каждому этапу — свой вход, свой выход, свой список чтения.
2. **Одна квитанция — одно место.** Вербатим автора остаётся в `verdicts/`
   и LIVING-NOTES (архив). Урок вписывается **тому, кому принадлежит**:
   урок историй — SOL, каста/гардероба — MERCURY, сцены — VENUS, сборки —
   EARTH, системный закон — LAWS (только через вердикт, §9).
3. **Дисциплина чтения.** У каждого файла планеты разделы «ЧИТАТЬ ПЕРЕД
   РАБОТОЙ» / «НЕ ЧИТАТЬ». За сеанс — файл планеты + входы. LIVING-NOTES,
   TASTE, NICHE целиком за сеанс не открываются никогда.
4. **Винтаж-баннеры** на `_TEMPLATE.md` и `EXAMPLE-T4-44.md`: ecchi-ключ
   мёртв (v1.2.0), мастер шаблона — `raw-plus.json`.
5. **Данные-активы не переезжают** — они получают владельца-планету
   (расы→MERCURY, позы/кинетика→VENUS, NEG-данные→EARTH, machine→FURNACE).
   Трогать 860KB спек ради перестановки — та самая полумера.
6. **POS-бюджет — вынесен автору** как открытый вопрос (не решаю сам).

## 5. Чего НЕ хватало (и появилось в v2)

- **SOL**: этапа мозгового штурма не существовало — раскрытие начиналось
  сразу с полей истории. Теперь: шторм образов → идея → HEAT → 24 истории.
- **HEAT как артефакт**: шкала тепла объявлялась строкой закона; теперь
  SOL заявляет её в шапке батча и назначает тир каждому слоту.
- **Право на бунт**: «кладёт хер на правила ради шедевра» жило в духе, не
  в протоколе. Теперь: `break:` ≤2/батч, помечено, оплачивается вердиктом.
- **LUNA**: микро-ядро ОС. Раньше ОС писались из общего чана и тащили
  фурнитуру батча (вердикт T5-05).
- **ULTIMATE DICE**: палитры/волосы/глаза/способ раскраски раздавались
  «наугад с оглядкой». Теперь: кубик с записью бросков и легальными
  перебросами только на коллизию.
- **ДРЕССЕР-протокол** как отдельная работа: «одет / не одет / чем тогда
  прикрыт» — раньше поле `outfit`, теперь развилка с каналами покрытия.
- **Блокнот печи**: ошибки латались в тексте и умирали в чате. Теперь
  `furnace-ledger.json`: класс закрыт только искоренением (правило /
  данные / гейт), не латанием.
