# {{IECODE}} — IMAGE EDITOR STATE PACK · «{{NICKNAME}}» · v3 (эконом)

> **Назначение:** промпты для Image Editor — картинка персонажа живёт текущим
> состоянием чата. **База — канон-портрет L02** (одета, нейтрально), НЕ
> титульник. Три типа секций:
> **ST** — состояние поверх базы (только дельта),
> **BG** — фон чата (полный промпт, «no humans»),
> **PP** — профильная PNG на белом фоне (full body).
>
> **v3 — эконом (вердикт v1.4):** состояний много = дорого по токенам.
> В пачке ровно **6 промптов**: 4 ST (шкала одежды 3 ступени + 1 характерное)
> + 1 BG + 1 PP.
>
> **Правила дорожки:**
> 1. ST — ТОЛЬКО дельта. База (канон-ран L02) не повторяется.
>    Исключение — «кадр Б» (правило 8).
> 2. Имя персонажа не входит.
> 3. Бюджет: ST ≤ 45 токенов · кадр Б ≤ 90 (полный кадр) · BG ≤ 90 · PP ≤ 60.
>    Только физика.
> 4. Регистр **R+** — эччи/джага-джага: декольте, бельё, стыд — рабочая
>    валюта. Explicit-анатомия — НИКОГДА; R18 — отдельной ревизией бота.
> 5. Каждое состояние привязано к триггеру или уровню лестницы L03.
> 6. Канон-константа белья: цвет волос персонажа + акцент канона. Не менять.
> 7. Закон языка: промпты — EN only. Закон формата промптов: ноль звёздочек —
>    промпт = теги, не проза (звёздочный ритм „речь“ *действие* „речь“ — для
>    текстов карточки, не для POS).
> 8. **«Кадр Б» (v0.5, двухкадровый переход):** 1–2 из ST помечаются «кадр Б»
>    — это НЕ дельта, а ПОЛНЫЙ кадр: канон-ран L02 verbatim + та же
>    палитра/свет/ракурс, что у рендера SO-AV (кадра А) + другое действие в
>    той же сцене. Порядок: рендер кадра А → рендер кадра Б → motion-луп
>    из А в Б. Подробнее — ARCHITECTURE.md, дорожка Motion.

## Как применять

1. Определи доминирующее состояние сцены (триггер / уровень лестницы).
2. Скопируй промпт → Image Editor → примени к базовому портрету.
3. Шкала одежды накатывается по порядку; конфликтные — не смешивать.
4. Сброс к базе — заново открой базовый портрет в редакторе.
5. BG и PP — отдельные слоты, со ST не смешиваются.
