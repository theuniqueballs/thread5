## 1. Как устроена площадка (что важно знать писцу)

**Карточка бота Yodayo — поля (реальные, из API):**

| Поле | Что несёт | Нюанс |
|---|---|---|
| `name` / `nickname` | Публичное имя бота / короткое имя в чате | nickname — как LLM обращается к персонажу |
| `description` | **Главное описание = де-факто персона** | У большинства ботов `char_persona` ПУСТ — вся персона живёт в description |
| `char_greeting` | Первое сообщение | У большинства формат `*действия*` + `"речь"` (звёздочная проза). НАШ ВЕРДИКТ v1.4.2: формат верный, но звёздочки — строго вокруг прозы; реплика внутри `*...*` — грубая хуйня; ритм `"речь" *действие* "речь"` |
| `greetings[]` | Альтернативные приветствия | <1% ботов используют — свободная ниша |
| `example_dialogue` | Образцы диалога | Большинство пусто — тоже ниша |
| `world_scenario` | Сценарий мира | Часто пуст, сценарий вшивают в greeting |
| `categories[]` | До ~5 тегов из 41 категории | Это SEO площадки |
| `lorebooks[]` | Записи лорбука с триггерами | У топ-ботов встречается |
| `llmsys_preset` | Системный промпт | Дефолт платформы: `Write {{char}}'s next response in a fictional role-play between {{char}} and {{user}}.` |
| `llmparams_preset` | Параметры LLM | Модель **Nephra 24B**, temp 0.9, top_k 100, top_p 0.9, min_p 0.05, rep_pen 1.1, ответ ~300 токенов |
| `content_rating` | PG / R18 | см. §5 |
| `thumbnail_photo` | Обложка/аватар | Портретная, ~9:16 (240×432, 296×432, 720×1280) |
| `background_photos[]` | Фон чата | Любой ориентир, чаще вертикаль (1536×1024, 1038×1516) |

**Движок:** Nephra 24B любит короткие ответы (~300 токенов), высокую температуру — бот должен нести характер в greeting и description ЖЁСТКО, иначе плывёт.

**Ключевой вывод по карточке:** площадка прощает пустые поля, но **не прощает пустого greeting** — вся конверсия «зашёл → остался» происходит в первом сообщении. Топы по сообщениям = топы по сильным greeting'ам.

## 3. Жанры: что реально заходит

### 3.1 Формулы-победители (сводка топов)

1. **Инверсия тропa + бытовая близость** — «Mallory hates you»: все ждут цундэру («злая = любит»), бот честно ненавидит без причины. Юмор + драма на сломе ожидания.
2. **Опасный партнёр / запретность** — Criminal boyfriend, Biker boy, Marry him to pay the debt: долговая петля, криминал, принуждение к выбору.
3. **Монстр-гёрл + быт** — «Kuchisake-onna Girl at Monster High», «Living with worst Cat Girl»: невозможная соседка, комедия проклятия.
4. **Песочница/RPG-мир** — RPG MECHA Academy, Hogwarts RPG, create your own: максимум сообщений (мир → длинные кампании), меньше лайков на сообщение.
5. **Мужской харизматик для женского POV** — 43% ботов Male-гендера; ядро — драма с уязвимостью под бронёй.

### 3.2 Эмоциональная сетка

| Регистр | Что заходит | Пример-паттерн |
|---|---|---|
| Вражда→притяжение | сильнейший крюк | enemies to lovers, bully, ненависть |
| Опасность→доверие | второй по силе | якудза, криминал, стигма |
| Забота→обида | женские POV | гвардеец, опекун, «принцесса» наоборот |
| Комедия быта | удержание | кошка-соседка, чай-«безопасный», интрудер |
| Ужас→жалость | нишевый топ | kuchisake, призраки, «мама-монстр» |

### 3.3 Название = второй движок

- **Эмодзи-крюк** в названии (🏍🚪🐱💢🧢🍵) — визуальный стопкер в сетке
- **Прямая речь как название** («Neh... do I look... kawaii?», «please drink the tea it's safe») — голос персонажа в сетке
- **Вопрос-ловушка** («Marry him to pay the debt, will you?», «Is my crush really gone»)
- Двоеточие/тире с ролью: «Luke Morandi — Enemies or Lovers?»

**Сюжетный минимум, который работает в greeting:** место + конфликт в первом абзаце + реплика с характером + крючок-вопрос или провокация в финале.

## 7. Технические выводы для нового документа

1. **Greeting — король.** 300–500 слов, `*действия*` + `"речь"`, минимум один «момент-картинка» и одна реплика-визитка.
2. **description = персона** (поле `char_persona` почти все игнорируют) — пишем компактный досье-блок: кто, как говорит, чего не делает НИКОГДА (анти-флор персонажа).
3. **example_dialogue — свободное преимущество**: 90% ботов пусто; 3–4 пары реплик задают тон модели лучше длинного описания.
4. **Альтернативные greeting'и (`greetings[]`)** — <1% ботов: бесплатный A/B-тест первых сообщений и повторная активация.
5. **Лорбук** — для миров (RPG-механика), не для бытовых ботов; 5–8 записей с триггерами.
6. **Картинки**: аватар ~9:16 портрет, фон — вертикальный интерьер/сцена; оба грузятся через thread5 Special Orders.
7. **Категории**: максимум 5; формула топов — `[Drama, Gender: X, Roleplay, Scenario, +1 фирменная]`.
8. **Название**: эмодзи + прямая речь/вопрос-ловушка; имя персонажа отдельно в nickname.

## 8. Риски и ограничители

- **Плывун характера на temp 0.9**: без жёстких «никогда-не» в description бот за 20 сообщений теряет крученость → анти-флоры обязательны (аналог hard-флоров thread5, но для текста)
- **Троп-усталость**: чистые «cat girl roommate»-клоны живут в медиане (6♥); выигрывает только инверсия
- **R18-политика**: в PG-зоне эччи на обложке допустим, гениталии/акт — нет (X/XXX-законы thread5 совпадают с PG-политикой Yodayo один в один)
- **Дубли-каноны**: имена известных персонажей в имени/POS бота триггерят защиту площадки — OC-имена только в nickname, обложка — дескрипторами (тот же закон, что в RAW+)
