# examples/websocket — референс, не запускаемый код

Сниппеты из платформенного шаблона (socket.io чат + широковещательный
канал). Зависимости (`socket.io`, `socket.io-client`) в `package.json`
НЕ объявлены намеренно: живой прилавок thread5 их не использует — это
справочник на случай, если понадобится живой канал.

Запуск, если понадобится:

```bash
bun add socket.io socket.io-client
bun run examples/websocket/server.ts
```

Замечания по безопасности при подъёме в прод:
- `cors: { origin: "*" }` в `server.ts` — только для локальной разработки;
  в проде ограничь origin доменом прилавка;
- сервер слушает порт 3001 — держи его за тем же прокси, что и приложение.
