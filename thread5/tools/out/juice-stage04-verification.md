## 3. ЧЕГО КОУЛ НЕ ДОКОПАЛ (находки той же археологии)

1. **Фейс-контроль с числовыми критериями** (01-SOL:134–137): «житель дома —
   да/нет (≥2 совпадений с профилем дома)», «гэг-стек ≥3 крючков, эталон
   плотности — Сью» — барьер канонизации конкретнее коуловского «в канон /
   доработать / reject».
2. **species_collision** (01-SOL:139): «При дебюте ОС её вид исключён из
   NICHE-слотов батча (policy.species_collision)» — закон дебюта, которого
   нет у Коула; стыкуется с его §8 (первая Луна = face lock).
3. **Элемент несёт тему заказа** — практика маппинга T5-10: GALE → Zia
   (Frenzy, «единственный канонический регистр потери контроля»), STEEL →
   Nix (Cyberpsychosis), STORM → Doe (No man's Sky). У Коула это рассеяно
   между §4.4 и §5; на деле — главное правило перевода заказа в момент.
4. **AM-05** («Тема-декорация: убери — не изменится») — готовый тест для
   чеклиста §11 «Theme-words батча отсутствуют?».
5. **special-roster.json** — вторая полка канона (гостевые персонажи, канон-
   ран вербатимом в первых ~10 токенах); Коул знает только oc-canon.json.
6. **Карта ротации T5-06–T5-14** — 9 батчей × 3 OC, ни одного повтора подряд.
   Гигиена реальна, но НЕ кодифицирована: правила Коула §7.2–7.3 — первые
   кандидаты в закон.
7. **Окно/бёрн касаются и OC** (T5-10: «0 повторов поз (33/33 новых)… burn-
   реестр (19 кодов) — 0 назначений» — счёт по всем 33 слотам включая OC);
   чеклист Коула этого слоя не упоминает.
8. **«Простенько» = FAIL EXP-аудита (T5-07)** — барьер качества, родственный
   «анкете» Коула, старше этапа; в таблицу болезней стоило добавить строку.

## 5. ЧТО ДЕЛАТЬ (писцово)

   Thesis≤10 / Gap / Umami / Gaze / Door / Register-поведение / Env-мир) —
   рабочая форма OC-блока; механизмы (off-theme, VERBATIM, имена вне POS,
   class floor, version bump, ротация) не трогать — они уже стоят.

   использовать как эталон заполнения формата (Zia-карточка дословно собрана
   из канона — образец перевода заказа в момент).
3. Чеклист §11 — в Earth-протокол с ближайшего батча (третий чеклист серии:

4. Три новых чек-пункта в чеклист: «три Door разные», «≤1 cannon в тройке»,
   «Register не токен в POS».
5. Doe-vials поправка писца: пробирки — слот-пропс T5-10 (GTFO-перекрой),
   не канон; в каноне Doe — очки, банд-эйд, чешуи, рог-ветви, SPORE.
