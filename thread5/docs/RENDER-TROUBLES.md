## Чеклист перед сдачей (по этому каталогу)

- [ ] видовая анатомия вместо вид-слова: raccoon/atlas-moth тест — «какой дефолт рендера подменит вид?» (Б8)
- [ ] героиня не сидит над дырой/люком в полу; давление снизу показано физикой сцены (Б9)

- [ ] R+ слот: заявка-вещь — первый элемент кадра, зрелище после неё (В16)
- [ ] рядом с реквизитом нет обиходных идиом («riding honest», «cheap-X»); строка лица не начинается с существительного; рисковый слот несёт NEG text/caption (В17)
