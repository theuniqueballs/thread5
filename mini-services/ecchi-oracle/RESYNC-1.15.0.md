# ECCHI-ORACLE — пересинхрон 1.15.0 (2026-11-19)

Пак ECCHI-ORACLE-1 был собран под эру **2026-11-18** (гейты 1.14.0, raw-plus 2.1.0,
метка-паспорт в POS легальна). По В34/В35 (вердикт автора по T5-25, 697b37f)
доктрина клейма перевёрнута: **метки в POS запрещены, клеймо = вплетение 1:1**.

## Что пересинхронено сейчас (oracle-service/index.ts)

- **yStampChecks → v1.15.0** — зеркало `check_ystamp` в tools/gates.py:
  (1) bannedMarkers в POS → FAIL (Y-STAMP:/«класс»/CAM-коды/corridor-токен,
  ловится и без карты); (2) первичный детектор вплетения — копипаст-юнит 1:1
  подстрокой; стемы — только диагностика (minWeaveStems=4 → no_weave /
  mismatch «пересказано/чужая карта»); (3) исполнение вне строки вплетения
  ≥2 стемов; (4) В33: R+/X при классе «—» → FAIL; (7) коридор карты ≠
  Corridor: → WARN.
- **/ystamp** — печатает `weave` (строка 3 POS, копипаст 1:1) + `stamp_metadata`
  (паспорт чипа, в POS не идёт) + `weave_rules` (позиция/запреты/камера OPENER/
  коридор физикой claim-строки). Формат-метка как продукт изъята.
- **/audit** — блок `stamp` теперь `{card_id, weaved, registry_version, era}`.
- **/health** — era: `Y-STAMP v1.15.0 (В34/В35...)`.
- **/taxonomy** — блок y_stamp заменён законом 1.15.0 (старый формат-блок
  corridors.json был эпохи метки).
- **/volt** — скелет берёт карту из живого реестра camera.json (не фолбэк).
- **Пути** — knowledge (ecchi-oracle/) и сервис ищут реестры треда по нашей
  раскладке `thread5/mini-services/*`: camera.json 1.15.1 (512 карт) и
  gates.json подхватываются из `thread5/specs/` живьём.

## Что осталось (честно, без угадайки)

- **Датасет**: категории `y-stamp` (32) и `audit` (44) — примеры эпохи 1.14.0
  (метка-формат). Пересборка: `dataset/build.py` после обновления
  `taxonomy/source/*` под В34/В35. До того LLM-режим может отвечать по-старому:
  **rule-engine приоритетнее** в споре.
- **THREAD-CHAIN.md промпты Т1–Т4** — сверить при следующей итерации (этап
  EARTH: «клеймо 1:1 из карты» — теперь это `weave`, не `stamp`).
- **Файнтюн (QLoRA)** — не запускался; обучение по старому датасету не делать
  до пересборки категорий.
