# thread5
Batch-Prompt Conveyer Belt

Конвейер промпт-батчей для аниме-рендеров (Tsubaki.2 Pro → Yodayo).
Наследник THREAD 4 — на новом ядре, без посредников.

## Петля (всё, что имеет ценность)

```
тема (автор, чат)
  → контракт (писец показывает экспозицию в чат)
    → батч (файл в batches/, RAW+ формат)
      → рендер (автор, Tsubaki.2 Pro) → пост (Yodayo)
        → вердикт (автор, чат) → квитанции в живые документы
```

Чат — двигатель. Файлы — память. Больше ролей нет.

## Структура

- `batches/` — батчи T5-NN (RAW+ / данбуру-формат) + `_TEMPLATE.md`
- `docs/` — LAWS.md (рабочий лист писца), TASTE, RENDERER_FACTS, NICHE, LIVING-NOTES, EXAMPLE-T4-44, ARS-NOVEAU, RENDER-TROUBLES
- `specs/` — данные-активы T4 (позы ×240, палитры ×120, носители ×280, OC-канон ×20, …)
- `verdicts/` — вербатим-вердикты автора по батчам

## Ветви

- `main` — полный тред (личные данные автора на месте)
- `friend-pass` — **Friend's Pass**: всё для локальной работы, ничего личного автора (см. ниже)

## Законы кратко

- Формат: RAW+ (Danbooru-скелет, без прозы в POS), 24 слота = 3 OC + 21 мейн + EXP-оверлей
- Hard-флоры никогда не расслабляются; X-слоты изъяты по умолчанию
- Окно ротации: позы/палитры последних 3 сданных батчей не повторяются
- Единственный законодатель — вердикт автора после рендера

Полная версия законов: `docs/LAWS.md`.

# FRIEND'S PASS

Ветка `friend-pass` — то, что можно отдать другу для локального использования:
тестов, приколов и собственного удовольствия. Машина работает полностью,
личного автора в ней нет.

## Что внутри

- Прилавок (Next.js): список батчей, копировалка (одна строка = один слот,
  POS+NEG, зелёные отметки отработанных), разбор, вердикт-форма, память.
- Крафт-активы: `specs/` — позы ×240, палитры ×120, носители ×280, кинетики
  ×107, нишевые архетипы и двери, bans, policy, RAW+.
- Крафт-знание: `docs/` — LAWS, NICHE, RENDERER_FACTS, ARS-NOVEAU
  (истории до тегов), RENDER-TROUBLES (каталог травм рендера → лечение).
- Шаблон батча: `batches/_TEMPLATE.md`.

## Что вычищено (ничего личного автора)

- Батчи T5-01/T5-02 и все вердикты
- `docs/TASTE.md`, `docs/LIVING-NOTES.md`, `docs/EXAMPLE-T4-44.md`
  (личные квитанции и проза автора)
- `specs/oc-canon.json`, `specs/oc-body-archive.json`, `specs/golden-corpus.json`
  (личные персонажи и корпус) — оставлены пустыми заглушками

## Как запустить

```
bun install
bun run db:push   # если нужен prisma
bun run dev       # прилавок на :3000
```

## Как пользоваться

1. Пиши батч по `docs/LAWS.md` + `batches/_TEMPLATE.md` (формат RAW+).
2. Проверяй себя по `docs/RENDER-TROUBLES.md` (чеклист в хвосте).
3. Клади файл в `batches/` — прилавок сам его распарсит.
4. Свой OC-канон — в `specs/oc-canon.json` или прямо в строке `Canon:` слота.

Правило одно: hard-флоры не расслабляются никогда.
